## ✨ Fonctionnalités clés

- **Design Immersif & Futuriste :** Une interface utilisateur ultra-moderne avec un style "glassmorphism", des arrière-plans dynamiques, et des effets lumineux (néons/glows).
- **Animations Avancées :** Utilisation intensive de `framer-motion` pour des transitions fluides et des interactions de défilement (scroll).
- **Effets WebGL (Three.js & VGPU) :**
  - **`ShapeWaves` :** Arrière-plan animé généré par des shaders VGPU dans la section principale (Hero).
  - **`PaperCrumple` :** Un effet 3D interactif de papier froissé appliqué à la photo de profil, qui réagit au glisser-déposer (réalisé avec `three.js`).
  - **`TechText` & `DepthText` :** Des composants de textes interactifs et animés, rendus sur canvas HTML5.
- **Performances optimales :** Les composants graphiques complexes sont chargés dynamiquement côté client (`next/dynamic` avec `ssr: false`) pour ne pas bloquer le chargement de la page initiale.

## 🛠️ Stack Technique

- **Framework :** [Next.js (App Router)](https://nextjs.org/)
- **Langage :** [TypeScript](https://www.typescriptlang.org/)
- **Style :** [Tailwind CSS v4](https://tailwindcss.com/)
- **Animations UI :** [Framer Motion](https://www.framer.com/motion/)
- **Graphisme 3D / Shaders :** [Three.js](https://threejs.org/) & [VGPU](https://github.com/vercellabs/vgpu)
- **Icônes :** [Lucide React](https://lucide.dev/) & [React Icons](https://react-icons.github.io/react-icons/)

## 🚀 Installation & Démarrage local

Pour lancer ce projet localement sur votre machine :

1. **Cloner le dépôt**
   ```bash
   git clone https://github.com/aminejhilel/portfolio-.git
   cd portfolio-
   ```

2. **Installer les dépendances**
   ```bash
   npm install
   ```

3. **Lancer le serveur de développement**
   ```bash
   npm run dev
   ```

4. **Ouvrir le projet**
   Rendez-vous sur [http://localhost:3000](http://localhost:3000) dans votre navigateur pour voir le portfolio en action.
